## 寫法原則

- 數字、品牌、價格全部只用圖裡有的，沒有另外編。
- 口吻跟作品集文案一致：講具體的事，不用形容詞堆砌，不喊口號。
- 每篇結尾一段帶回統包先生的做法，但只寫流程上真的在做的事。
- 沒有破折號、沒有 emoji、沒有「首先／其次／最後」式的八股結構。

## 審稿時請特別看

1. `ac-brands-4-tiers`：品牌分級是你們影片的立場，對外發佈前確認要不要點名品牌。
2. `renovation-14ping-cost`、`bathroom-add-cost`：價格是 2026 年的實際案場數字，之後要定期更新。
3. `site-requirements`：「師傅說」那幾段是圖上的原話改寫，口氣比較直，可以斟酌。
4. 每篇最後一段提到的「統包先生的做法」，有哪一條實際上沒在做的，刪掉。
